## 🚀 O que estou construindo

### 🎮 Ludus

Plataforma de gamificação educacional para estudantes, professores e gestores. Reúne turmas, missões, jornadas de aprendizagem e recompensas, com acompanhamento das atividades pelo professor.

**Tecnologias:** Python · Flask · SQLAlchemy · PostgreSQL · React · Vite · Tailwind CSS

### 💰 Finanças a Dois

Aplicativo de planejamento financeiro para casais, com contas individuais, cartões, faturas, orçamentos, recorrências e projeções. O compartilhamento de informações acontece mediante consentimento de cada pessoa.

**Tecnologias:** TypeScript · Node.js · SQLite

### 📝 Intersticial

Diário para registrar o que acontece entre uma tarefa e outra: abrir, escrever, salvar e continuar. Inclui histórico, calendário, classificação posterior dos registros e resumo mensal.

**Tecnologias:** JavaScript · Python · FastAPI · SQLAlchemy · SQLite · Vite

### 📷 Conferir

Leitor de gabaritos que processa fotos e imagens da câmera no navegador. Combina leitura de marcações, revisão manual, leitura em lote e exportação de resultados para apoiar a correção de avaliações.

**Tecnologias:** HTML · CSS · JavaScript · OpenCV.js · WebAssembly

### 🤖 Dev Agent Skills

Coleção de skills reutilizáveis para agentes de IA, com fluxos de levantamento de requisitos, planejamento, implementação, revisão de código, segurança e estudo guiado.

**Foco:** desenvolvimento assistido por IA · instruções reutilizáveis · aprendizagem
